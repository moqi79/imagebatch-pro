# 图标资源

放置应用图标文件：

| 文件名 | 尺寸 | 用途 |
|--------|------|------|
| icon_16x16.png | 16×16 | 任务栏小图标 |
| icon_32x32.png | 32×32 | 标题栏图标 |
| icon_48x48.png | 48×48 | 文件管理器 |
| icon_128x128.png | 128×128 | 应用列表 |
| icon_256x256.png | 256×256 | 高清图标 / 源 |
| icon_256x256.ico | 256×256 | Windows 打包用 |

打包时 PyInstaller 会引用 `icon_256x256.ico`。
